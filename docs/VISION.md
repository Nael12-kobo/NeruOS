# NeruOS Vision

## Mission

Build a thoughtful Arch-based Linux desktop that feels cohesive, customizable, fast, and approachable without hiding the flexibility of Linux.

## The problem

A distribution can be technically capable and still feel fragmented: settings are spread across tools, visuals vary between applications, and users may be unsure which compatibility claims are dependable.

NeruOS aims to reduce that friction through a consistent desktop identity, carefully selected defaults, first-party utilities where they add real value, and clear documentation.

## Product principles

1. **User control** — customization should be easy to discover and reversible.
2. **Honest compatibility** — show verified support and known limitations.
3. **Performance with restraint** — visual effects must not become a tax on everyday work.
4. **Consistency** — apps and shell components share design tokens and interaction rules.
5. **Recoverability** — updates and configuration changes should have documented recovery paths.
6. **Open development** — roadmap, source code, issues, and decisions are visible.

## Intended audience

- Linux users who value a polished desktop.
- Developers and creators who want a configurable environment.
- Gamers who understand that compatibility varies by title and anti-cheat policy.
- Contributors interested in desktop Linux, Qt/QML, KDE Plasma, packaging, and system integration.

## What NeruOS is not

- It is not a guarantee that all Windows applications will run.
- It is not a promise to bypass kernel anti-cheat.
- It is not a macOS clone.
- It is not ready for production or daily-driver use at the prototype stage.

## Long-term direction

NeruOS starts with a Plasma-based foundation and a standalone Qt/QML UI prototype. The project may later introduce custom shell components and first-party applications as the design and engineering mature.
