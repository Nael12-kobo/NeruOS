# NeruOS Nebula Icon Pack v1.0

A set of 32 individual application and system icons for the NeruOS Nebula desktop concept.

## Contents
- `icons/256/` — 256 × 256 PNG icons
- `icons/512/` — 512 × 512 PNG icons
- `preview.png` — contact-sheet preview

The icons use a consistent navy tile with cyan, blue, and violet gradients. The outer corners are transparent. Each icon is a separate PNG file named by its application or function.
